El Document Object Model (DOM) es una interfaz de programación para documentos HTML y XML que representa la página para que los programas puedan cambiar la estructura del documento, estilo y contenido.

Un evento es una acción o suceso que ocurre en el sistema que se está programando (como un clic de ratón o presionar una tecla), sobre el cual el sistema nos avisa para que podamos responder.

La delegación de eventos es un patrón que consiste en agregar un único manejador de eventos a un elemento padre para gestionar los eventos de todos sus elementos hijos mediante la propagación (bubbling).
